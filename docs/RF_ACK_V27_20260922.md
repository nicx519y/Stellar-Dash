## ACK 行为与时序

普通模式继续每 100ms 请求 ACK，失败预约仍为请求包保护时间＋1750μs。实验快速恢复和后台短测默认关闭。

成功路径增加独立 `resume` 截止点，不覆盖原始响应超时。只有连接稳定、同会话/频道/generation/请求序号、普通短 ACK、2M PHY、没有频道或快速恢复事务时，才令：

`resume = min(原预约终点, TX 收到合法 ACK 的本地时间 + 250μs)`

TMR1 真正执行结束动作后才能恢复 TMR0 输入；定时中断迟到不会由 TMR0 抢先释放。重复/过期 ACK 不推进期限；取消、切频道、重连清除旧预约。长 ACK、握手和事务继续用完整窗口。SDK 无身份的旧 TX_FINISH 不获得新 ACK 所有权。RX 继续按冻结的 ACK 长度和启动时间执行发送保护、重启接收。

250μs 为工程初值，不是实测硬件上界。旧保护和 SDK 调用均保留；收到 ACK 不等于 RX 已重新就绪。若出现首包损失/时序故障，不能仅凭平均输入率提升宣布通过。

## 空口及诊断格式

### 空口 v5

5/7B DATA 与 12B 事务长度不变。连接握手版本由 4 升为 5，版本不一致不启用通信。

普通 5B ACK：byte 0 现有头部；byte 1 请求 DATA 序号；bytes 2..4 为 LE24：低 12 位 expected，高 12 位 missing。received=expected−missing。有效范围 expected=1..4095、missing≤expected。无样本/越界时质量有效标志清零，计数填零，但合法 ACK 仍确认链路。不得饱和截断或将无效质量当零丢失。带配置/事务的长 ACK 保持其原字段，不因计数超过 255 自动使用长 ACK。

### TX 调度统计

新的附带记录类型 **11**，52B 数据通过已有 7B DATA 分片发送：`version=1, page=0/1, snapshot LE16, TX atUs LE32, spanUs LE32, counters[10] LE32`。两页同一冻结快照；替代原每秒 stats 记录，每秒发一页，一份完整快照约两秒。缺页不拼接其他快照。

计数顺序：

| 索引 | 字段 | 语义 |
|---|---|---|
| 0–3 | due / attempt / accepted / startFailed | 已处理时隙、SDK 调用尝试、两次启动调用均成功、启动失败 |
| 4–7 | ackSkip / pauseSkip / busySkip / guardSkip | 每时隙互斥归因 |
| 8–9 | late / missedEstimate | 延迟超过 32μs 的 IRQ 次数、绝对时钟推算漏节拍；不算 RF 缺口 |
| 10–13 | ackOk / ackTimeout / earlyRelease / ackUs | 稳态 ACK 成功、超时、提前释放安排次数、实际预约累计微秒 |
| 14 | controlSkip | 控制包回调排空造成的跳过 |
| 15–17 | packets5 / packets7 / packets12 | SDK 接纳的对应长度包数，不承诺空口成功 |
| 18 | lateMaxUs | 开机以来最大定时迟到；唯一非累加字段，禁止作差 |
| 19 | cancelSkip | 未执行 SDK 尝试的取消/无可发操作时隙 |

维护占用从请求启动到定时器实际释放或射频取消结算一次。包含请求包，不把成功提前结束后节省的时间仍算成占用。manager 的保守预约预算不因此解除，其显示与实际占用是不同指标。

USB **RHT5**（magic 0x35544852），32B、5 页：magic u32；snapshot u16；page u8；version=1 u8；TX atUs u32；spanUs u32；4 个计数 u32。监视器有界重组，完整后才发布 `rfTxMetrics`。计数/时钟按 u32 模运算，拒绝复位导致的异常增量；新字段缺失显示不可用。USB 时间只用于新鲜度和日志区间，不参与 TX 时长计算。

### RX 输入间隔

仅监视器租约开启时统计，不产生 RF 包。使用相邻有效 DATA 的 RX 接收时间戳；每包至多三次分桶比较。分桶上界（μs）：125、250、500、1000、2000、4000、8000、∞。两秒结算一次，同时记录区间最大值。

USB **RIG5**（magic 0x35474952），与 RHT5 相同 16B 页头，3 页数据依次为 8 个桶计数、最大间隔 μs、结算时频道、速率、保留零。五/七字节都计入，不能等到按键变化才计数。普通 ACK 和切频造成的间隔不剔除。

直方图分位数是**桶上界**，不是精确单包 P95/P99；溢出桶表示 >8000μs。重连后首包没有同会话前驱，不混入间隔直方图；断连窗口在报告中另列。它不能独立证明真实空口边界或 PLL 时序。

### 临界区与诊断开销

辅助记录使用两个独立准备缓冲；主循环执行编码/CRC，关中断区仅复核 generation 并发布指针。诊断历史遍历与序列化移到锁外。统计快照只复制必要计数。SPI 快速输入、DMA 和输入保护时间不变。

实验状态正常 OFF 时改为状态变化更新、5 秒补报；实验活跃仍每秒上报。新的统计页替代旧 stats，不增加独立无线时隙。按当前三遍补传估算，稳定 OFF 时统计页增加的附带量低于减少的实验状态补报量；实际 7B 比例仍以计数为准。延迟记录关联、三遍有界传输及部分记录显示保留。

## 用户测试步骤

1. 保留旧版本日志。更新匹配 TX/RX，重开新监视器，确认 RX 0x1927、协议 v5；前两个完整快照到齐之前，新 TX 指标显示不可用是正常的。
2. Channels 关闭自动，固定到同一频道（基线频道 24）；保持距离、USB 接口、速率和环境一致。默认快速恢复关闭。
3. 8K、4K 分别执行测量关/开，各观察至少 120 秒；其中一段无按键、一段持续按/松、同时按多个键。保存原始 JSONL，不删除尖峰。
4. 1K/2K 确认输入、配置及重新连接正常。再测试自动模式和反复手动切频道；这些区间单独保存，不混进固定频道基线。
5. ACK/DATA 丢失、重复、迟到、错误身份、SDK 启动失败、完成事件丢失复用已有默认关闭的限时故障注入入口；正常 ACK 优化测试不要同时开启实验快速恢复。不能使用精确注入时，遮挡/单边重启只作为链路恢复测试，不声称覆盖了特定单向故障。
6. 检查所有故障有界结束、不永久卡键；拔插及各类故障至少 100 次、8K 两小时由用户执行。无数据的窗口保留，分别记成功、失败、缺测。

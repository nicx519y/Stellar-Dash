## 修改

仅RX及验证文件，不修改TX、STM32、空口格式、RF/ACK时序或烧录流程。

1. 接收回调的短包长度判断强制内联。原-Os编译把同一两次比较的小函数放在Flash，并在逐包路径反复调用。
2. RX局部把fast状态机的逐DATA入口与判断置RAM，共享状态机逻辑和TX构建不变。调试输入记录仅在need_fault_input/need_clear_input待处理时调用；故障/恢复测量语义保留。
3. RX辅助重组使用两个32位覆盖掩码，实现与原64位seen规则等价的索引、代次、CRC和重复检查。消除逐片调用Flash __ashldi3/__lshrdi3；只改变RX实现，不改变线上字节。
4. 辅助队列16槽→64槽（有效63，全部为7B包时可容纳约7.875ms的8K流）；单次后台处理上限15→32片，保持每步一个分片、可抢占、队列空即返回。增加1920字节BSS。容量覆盖已观察的5.8ms服务间隔，同时提高消费上限并降低逐包/逐片CPU成本，不能只靠扩容宣称持续吞吐已达标。

普通输入仍每个新序号生成报告，包括相同状态。报告队列仍4待发+1在途、500µs限制与中立优先规则不变。辅助丢弃仍完整计数，不隐藏缺失记录。

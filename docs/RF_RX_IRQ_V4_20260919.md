# RX IRQ v4：缩短高频输入临界区

## 变更

- RX 短 DATA 的纯解码/软件 CRC 计算在开中断状态完成。提交 FIFO 前重新检查 radio generation 与 RX 状态，阻止解码期间发生 SYN/切频道后提交旧输入。
- 输入队列仅接收私有解码器产物，消费时不再重新计算同一份本机生成数据的 CRC；旧格式空口输入仍由 decoder 验证 CRC。
- 控制命令仍维持原有原子事务处理，按键 FIFO 顺序、USB 背压及 50ms 中立输入保护保持。
- 新增 RHD1 第 3 页，build ID 0x1904；保持帧长、输入包、固定配对与 8K 默认速率。TX 不修改，本轮继续使用 dd46370d… 镜像。

## 诊断第 3 页

| 字节 | 含义 |
|---|---|
| 12–15 | RX SetRx 失败累计 |
| 16–17 | RX 分支入口到 rearm 返回的最大微秒数 |
| 18–19 | RX 分支入口到处理完接收包的最大微秒数 |
| 20–21 | 短输入提交临界区最大微秒数 |
| 22–23 | 输入队列消费关键段最大微秒数 |
| 24–27 | 原 ACK fail 路径累计（包含超时，不能只解释成发送 API 拒绝） |
| 28–31 | 新短包路径解码提交累计 |

数值是启动后累计最大值，微秒向上取整、65535 饱和；不包含回调前的硬件/SDK等待，也不代表全系统最长关中断时间或 P95。采用 SysTick 周期差、低频汇总，没有每包串口输出。

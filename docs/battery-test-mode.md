# XORA 屏幕电池测试模式

## 充电效率测试（2026-10-22）

屏幕 **Power → Charge Test → Start Test** 启动独立充电测试。与 Battery Test 互斥并共用现有 64 KiB 区域，一次保留一轮；先在 WebConfig 导出，再明确确认清空电池测试日志后才能开始下一轮。网页不新增启停命令或持续轮询。已有续航 v1 日志继续可读。

未插电时等待，已插电时从当前电量开始并标注中途开始，已充满时拒绝启动。每次插电开始新段，拔电结束该段并继续等待；断电间隔不计入插电或充电状态累计。暂停充电仍属于当前插电段，状态、阻止原因、故障与供电档位变化单独记录。测试不会更改负载、连接、休眠或充电策略。

`Full` 需要持续 30 秒新鲜有效数据确认，期间过期、缺口、拔电或退出 Full 均重置确认。充电时采样间隔超过 2.5 秒视为缺口，普通休眠时间不能豁免充满确认的采样连续性。SOC 100% 独立记节点，不替代 Full。确认充满自动结束；手动结束、24 小时超时、存储失败、重启均保留明确原因。充电测试不使用续航的保护恢复结束条件，重启不续跑。

每五分钟消费电源快照生成摘要，保存起止 uptime、首末 SOC、电池/输入电压及充电电流的最小、最大和均值、有效/缺失采样数、累计插电及充电状态时间，结束时补尾段。累计状态时长只覆盖相邻新鲜有效采样均确认对应状态的区间，未知时间不补算。20/50/80/90/100% 节点按新鲜采样首次到达记录，不从摘要插值；起点已超过的节点不倒推。

WebConfig 在电池测试来源下展示充电会话、独立充电段、节点耗时，以及电池电压/SOC 和输入电压/充电电流两张图。图线使用桶内均值与末尾 SOC，提示范围和采样数量；数据缺口、缺失桶不连线。记录完整性与充到满电结果分开：拔电中断可以拥有完整日志，但不是完整充电成绩。已知负载/供电变化、无效采样、重启或不完整读取均不能给出固定条件有效成绩。JSON/TXT 使用页面相同的分析函数。

### 充电日志 v2

分区头仍为 v1，原 128 字节槽、CRC 和最终提交顺序不变；充电记录正文 `data[0]=2`，`data[1]` 为会话。事件 120–127 依次为会话开始、分段开始、摘要、充电/供电状态变化、电量节点、分段结束、会话结束、质量变化。配置及通用背景事件沿用 100–114 的正文布局，但版本为 2；放电记录仍使用版本 1。

- 快照事件正文剩余 12 个 uint32：段编号、事件 detail、电池 mV、SOC 千分数、输入 mV、充电 mA、状态位、阻止原因、故障、采样 uptime、累计插电 ms、累计充电状态 ms。状态低 8 位为充电枚举，bit 8/9 为插电/有效，bit 10–12 为温控/输入限流/输入限压。节点 detail 为 SOC 千分数；结束 detail 沿用 1–5 原结束码，6 为拔电。
- 摘要正文剩余 12 个 uint32：起止 uptime、电池 min/max、输入 min/max、电流 min/max、首末 SOC、平均电池/输入电压、平均电流、有效数、缺失数、累计插电 ms、累计充电状态 ms。成对数值低/高 16 位存储，单位同快照；无有效采样的数值只作为编码占位，显示为空。
- 会话结束剩余 7 个 uint32：原因、会话 ms、插电 ms、充电状态 ms、存储暂停 ms、丢弃数、不完整标志。重启结束的时长未知，不能把编码 0 当成测量值。
- 保持 290 条摘要、60 条事件及终止余量；24 小时通常 288 个摘要，事件风暴仍受限并标记丢弃，终止记录优先。没有增加分区或自动擦除。`BatteryTest_RequestStart()` 保持续航语义，新增 `ChargeTest_RequestStart()`，沿用原读页/清空协议。

Mock 场景：`/view-logs/?mockLogs=charge-complete`、`charge-interrupted`、`charge-gap`、`charge-reboot`。选择电池测试并读取。对应主机测试为 `test_battery_test_recorder`、`test_screen_power`、`test_battery_test_layout`，网页运行 `npm run test:logs` 与 `npm run typecheck`。实机电流、充满状态及实际时长需另行验收；不把 SOC 换算为容量、充入 mAh 或能量转换效率。

本次实现验证：记录器和生产运行时 2 项通过，屏幕菜单主机测试在 Auto Sleep 开/关两个变体通过，网页日志/曲线/导出 32 项及类型检查通过。主控 `HBOX_SECURE_BOOT_REQUIRED=0 BUILD_DIR=build_battery_test` 增量编译通过，ELF 布局检查通过：D3 测试状态 1736 字节，ITCM 余量 1056 字节、AXI 尾部余量 1760 字节，MSP 保留至少 8 KiB。针对电池记录编译单元启用 Os 覆盖内联记录器，并将菜单确认函数放入现有 ITCM 启动复制范围，保留原内存余量检查门槛；宏重定义和 RWX 段警告仍存在。

Mock 浏览器核对正常完成、拔电分段、采样缺口，中英文、明暗主题及 390px 布局；缺口场景的真实 JSON/TXT 下载保持“记录完整但充电结果无法验证”。这些结果只覆盖主机和 Mock，不包含烧录、部署、实机充电或设备采样。

使用图片区尾部独立划出的 64 KiB 测试区，保留完整故障日志预算。生产存储入口已启用，仅在预留区域空白且没有旧图片跨界占用时允许开始。

## 操作

从屏幕 **Power → Battery Test → Start Test** 开始，确认界面说明周期存储会短暂暂停输入。`View Status` 查看状态和累计时间，`End Test` 提前结束。测试不保存 bootMode，不更改回报率、灯光、屏保或 Auto Sleep。

设置好负载后开始；仍插电时等待拔电，放电起点另外记录。单轮自启动起最长 24 小时。严重低电量保护后继续记录，插电、电压恢复达标并按旋钮完成恢复后自动结束。重启不自动续跑，而是把未结束记录标为中断；缺失时段未知。

WebConfig“设备日志”新增**电池测试**来源/类别，支持中文事件、五分钟电压/SOC 摘要、续航节点、JSON/TXT 全分页导出。放电时无需连接网页；完成保护恢复后再进入 WebConfig。屏幕沿用现有英文菜单字体体系。

普通 Auto Sleep 由用户设置，时间单独统计。首次保护验收至少包含一次关闭普通 Auto Sleep 的测试。软件记录不替代实际屏幕观察、CE 波形或保护电流测量；充电电流字段不是电池放电电流。

## 连续放电统计

测试会话 ID 用于组织整轮测试和后续充电恢复，不代表一次连续放电。WebConfig 根据现有 v1 放电起点和外部供电变化事件重建放电段，无需更改日志格式或固件。首次拔电开始一段；中途插电或开始充电立即结束当前段，再次拔电另起一段。严重低电量/保护事件冻结该段终点，后续充电和退出保护时间不计入放电成绩。

页面分别显示“记录完整性”和各放电段的有效性、起止 SOC、已观察时长、终止原因。只有到达保护且没有已知配置变化、无效/过期采样、采样缺口、缺失/丢弃或待落盘记录的放电段，才显示“有效放电至保护”。分页未加载完、读取异常和缺少测试起点时不能给出有效成绩；重启中断段的终点和完整时长未知。五分钟摘要中的缺口不能定位到段内哪一刻时，保守地将与之重叠的放电段标为无法验证。

“会话电池供电合计（含多段）”继续展示固件累计值，不作为单次续航成绩。有效放电结果只覆盖显示的起点 SOC 至保护，不能据此宣称满电续航。JSON 和 TXT 导出使用与页面一致的分段和有效性判断。Mock 场景 `/view-logs/?mockLogs=battery-interrupted` 演示放电 2 小时、插电 0.5 小时、再次放电 3 小时：显示两段，第二段成绩为 3 小时，会话合计为 5 小时。

## 空间与兼容

- STM32 故障区 `0x90560000–0x9056FFFF` 保留全部 64 KiB（512 槽），历史记录和 TX 日志不变。配置 bank B、升级区域和冻结烧录流程不变。
- 独立电池测试区 `0x90770000–0x9077FFFF` 为 64 KiB。首 4 KiB 保存版本化认领标记，正文/CRC/提交字依次写入并回读；余下 60 KiB 提供 480 个 128 字节槽。未知或提交不完整的数据不会被覆盖。
- 图片数据区缩为 `0x90600000–0x9076FFFF`，共 1472 KiB；扣除 4 KiB 头部后 JPEG 最大载荷为 `0x16F000`（1468 KiB），仍容纳 12 帧 RGB565。布局定义见 `common/user_storage_layout.h`；原资源区外框及首 64 KiB 兼容保护区保留。
- 图片上传 BEGIN、分页写入、提交、迁移擦除、删除和读取使用新边界；擦除向上取整至 4 KiB 后再次检查。网页从设备获取实际容量，管理端图片生成和 Mock 默认容量同步更新。
- 测试认领前逐块确认整个测试区空白，并检查当前/旧图片头声明的范围；即使尾部字节为 FF，图片声明跨界也拒绝。读取失败、未知头或非空历史同样拒绝，不迁移、删除或自动格式化。
- 旧超限图片不再作为可用背景读取。重新上传较小图片不会自动擦除测试区内的旧尾部；若仍有占用，测试继续拒绝启动，需要另行明确清理，不得把这类拒绝当成可直接格式化的故障。
- 记录复用 `fl_record` 的 96 字节正文、CRC、最终提交字，原故障格式不变。测试后端只追加，没有擦除能力。确认空间已擦除后直接使用，不额外擦除空白扇区。
- 预算为 290 条趋势、60 条事件、2 条终止记录；事件最后 8 条预算优先供保护/恢复使用。RAM 队列 16 条，普通事件最多占 12 条，并预留终止余量。
- **保留一轮完整测试，不自动清空/覆盖。** 已有测试时再次开始提示容量不足；导出不删除设备记录。WebConfig 可在测试停止后，经确认清空此来源的全部日志；仅擦除专用区并回读，头部最后擦除，成功后可开始新一轮测试。活动测试或新旧图片占用检查失败时拒绝清空，协议见[设备日志](device-fault-logs.md)。
- 旧固件和旧图片写入工具可能仍使用原图片上限，不能保证保留新测试区；回退前先导出。不承诺跨版本写入具有同样隔离能力。当前本地资源构建只在前部兼容保护区生成 4 KiB 空背景标记，不写入测试区。

## 记录与写入窗口

每 5 分钟保存首末 SOC、电压最小/最大值、有效/缺失采样数量、累计电池供电/普通休眠/已完成存储窗口耗时和丢弃数。只消费现有电源快照，不额外轮询；扣除两次样本之间实测的普通 STOP 时间后，间隔超过 2.5 秒时按约一秒间隔估计缺口，不能把该数量当成 I2C 硬件错误次数。这样正常五秒休眠维护不会反复消耗异常事件预算；清醒时的停采仍会记录。此扣除仅影响测试日志，电池保护策略的连续采样要求不变。阈值开始/取消来自生产策略计时状态，确认完成由电量状态转换记录，不用趋势摘要反推三秒保护。

专用队列不占用故障队列。同步主循环完成屏幕服务且 LCD DMA 空闲后，暂停输入、进入 QSPI 间接模式、写入至多一条记录、恢复映射/缓存和输入。暂停涵盖停止和恢复；摘要是生成该记录时的累计值，最终记录自身写入窗口不包含在此前统计中。

仅测试已启动或有终止记录待提交时申请写入。安装、升级事务、TX ISP、显示忙时不写。严重低电量关断先执行，再处理日志；保护期间不擦除。失败锁存，停止记录并保留 RAM 证据，不无限重试、不阻塞保护、不递归记录自身错误。启动准备超过 10 秒仍无窗口则取消并提示在游戏模式重试。

队列/配额不足标记不完整并累计丢弃；周期摘要和结束记录带计数。回读/写入失败通过来源状态显示。断电可能丢失最后未提交片段，原子提交不保证最后一刻动作必然落盘。没有正常终止记录的会话不能判作成功。

单次测试区扫描首次读取失败后，不再继续对其他槽位发出物理读取，避免把驱动超时放大到整区 480 次；该写入窗口失败后停止自动写入。后续用户读取请求独立尝试一次扫描，失败明确返回 I/O 错误，不把局部结果报成完整成功。驱动单次调用本身仍受现有硬件超时约束，实际暂停时长需实机验收。

## 新增类型与字段

公共字段：payload 版本/会话编号，信封中的启动编号、固件、单调毫秒时间、序号及 pending。新增来源 `battery`（记录来源值 3）、类别 4、正常级别 INFO=1，原 STM32/TX 值不变。

| 100 | BAT_TEST_START | 连接/输入模式、无线 Hz、亮度/屏保、Auto Sleep、主灯/环绕灯开关亮度效果、灯光配置和 Profile ID 校验值 |
| 101 | BAT_DISCHARGE_START | 拔电起始电压、SOC |

| 103 | BAT_CONFIG_CHANGED | 与起始配置相同；灯色/速度等额外变化由灯光 CRC 标识 |
| 104 | BAT_DATA_QUALITY_CHANGED | 数据质量、bit8 有效位、bit9 超过 2.5 秒的间断、样本年龄 |
| 105 | BAT_THRESHOLD_CHANGED | 新旧确认位图：bit0 低电量、bit1 严重、bit2 正常恢复、bit3 插电恢复 |
| 106 | BAT_LEVEL_CHANGED | 新旧状态：0 正常、1 低电量、2 严重、3 可恢复 |
| 107 | BAT_NOTICE_CHANGED | detail：0 结束、1 低电量提示、2 保护提示、3 状态查询、4 睡眠充电页；extra：前四种为显示标志，充电页为 0 等待、1 普通充电、2 快充、3 充满、4 故障 |
| 108 | BAT_PROTECTION_ENTER | 负载停机成功标志 |
| 109 | BAT_SLEEP_SUMMARY | 普通休眠转换，或终止时普通休眠 ms、WFI 总次数/等待 ms/失败数、暂停、门禁位图，以及普通/保护 STOP 各自次数、耗时和失败数 |

STOP 门禁：bit0 编译关闭、bit1 运行门禁关闭、bit2 复位、bit3 按键、bit4 中断屏蔽、bit5 电源采样忙、bit6 调试器、bit8 准备失败。WFI 统计不能直接等同硬件低功耗电流。

## 睡眠充电页（2026-10-22）

- 普通 Auto Sleep 或电池保护期间，检测到外部输入后持续显示充电页；只恢复 LCD，不恢复输入采样、灯光或 RF。普通屏保熄屏不是系统睡眠，不触发此页。
- 320×172 黑底，中央 76×38 灰色电池边框、灰色实心正极和灰色数字，无百分号。下方普通充电为灰色 `CHG`，快充为绿色 `FAST`，充满为绿色 `FULL`，等待为灰色 `WAIT`，故障为红色 `ERR`。充满显示实际 SOC，不强制改成 100；无效 SOC 显示 `--`。

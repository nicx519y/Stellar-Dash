# Channels 界面调整（2026-09-22）

仅更新 connect-monitor；TX、RX、STM32 固件及空口协议均不变。

- 删除独立 Channel Debug 卡片。Channel Events 恢复占满原来的栏位。
- Channels 卡片右上角恢复自动选频开关。关闭开关时，以当前有效输入所示的工作频道进入固定模式，避免自动跳到列表首项。若当前频道或连接状态没有新数据，暂不允许关闭，防止使用过期频道。
- 固定模式下直接点击频道列表项切换，可连续切换。自动模式下列表只展示评分。
- 切换后需 RX/TX 配置生效、双方频道一致且有新输入，才报告成功；超时和失败在 Channels 卡片内显示。

已通过 TypeScript 类型检查和构建。遵循用户要求，未运行回归、采集设备或烧录。关闭旧监视器进程后重新启动更新后的版本；不需烧录固件。

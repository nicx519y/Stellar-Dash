# BQ25895 1S2P 8000mAh 电池充电设计方案

## 1. 文档目的

本文记录 HBox 新版电源电路中，使用 BQ25895 为两块 4000mAh 锂电池并联组成的电池组充电时，推荐的硬件修改、充电参数、寄存器配置、启动流程和验证要求。

本文方案以安全、温升和循环寿命为优先，不以电池标称的最大允许充电电流作为日常工作电流。

## 2. 电池组规格与设计边界

电池组由两块相同的 4000mAh 单节锂电池并联组成：

- 连接方式：1S2P
- 标称总容量：8000mAh
- 标准充电电流：0.1C，即 0.8A
- 快速充电电流：0.2C，即 1.6A
- 最大允许充电电流：0.5C，即 4.0A
- 20°C 以下最大充电电流：0.2C，即 1.6A
- 恒压充电电压：4.2V
- 终止电流要求：小于 0.01C，即小于 80mA
- 允许充电温度：10～45°C
- 放电截止电压：2.75V

并联只增加容量和允许电流，充电电压仍然是单节锂电池的电压，不能按两节串联计算。

## 3. 推荐充电配置

推荐量产基准参数如下：

| 参数 | 推荐值 | 说明 |
|---|---:|---|
| 恒压充电电压 VREG | 4.192V | BQ25895 无法精确设置 4.200V，选择偏低的一档 |
| 快充电流 ICHG | 1.600A | 对 8000mAh 电池组为 0.2C |
| 预充电流 IPRECHG | 256mA | 对深度放电电池采用温和预充 |
| 终止电流 ITERM | 64mA | 低于电池要求的 80mA |
| 预充转快充阈值 | 3.0V | 使用 BATLOWV=1 |
| 重新充电阈值 | VREG-100mV | 约 4.092V 时允许重新充电 |
| 9V 输入电流限制 | 1.5A | 兼顾 1.6A 电池充电和系统负载 |
| 输入电压调节 VINDPM | 8.2V | 为 9V PD 输入保留线损余量 |
| 快充安全计时器 | 8 小时 | 与电池 0.2C 快充时间要求匹配 |
| BQ25895 热调节阈值 | 80°C | 该阈值监控芯片结温，不代替电池 NTC |
| 电池充电温度窗口 | 10～45°C | 由 TS 外部 NTC 网络强制执行 |

预计 1.6A 恒流阶段的理论充电时间约为 5 小时，加上恒压阶段后，完整充电时间通常约为 6～7.5 小时。

如需提供偏重循环寿命的慢充模式，可将 ICHG 动态降低到 0.8A，并把安全计时器调整到 20 小时。正常快充模式不建议超过 1.6A。4.0A 是电池给出的最大允许值，不是推荐的长期工作值。

## 4. 原理图必须修改的部分

### 4.1 增加 ILIM 硬件限流电阻

BQ25895 的 ILIM 引脚必须通过电阻连接到 PGND。在 `EN_ILIM=1` 时，实际输入电流限制取硬件 ILIM 和寄存器 IINLIM 中较小的值；ILIM 不应悬空。

推荐连接：

```text
BQ25895 ILIM（10脚） ── 270Ω、1% ── PGND
```

根据 BQ25895 的 `IINMAX = KILIM / RILIM`：

- 典型输入限流约为 355 / 270 = 1.31A
- 按 KILIM 最大值计算约为 390 / 270 = 1.44A

软件仍将 IINLIM 设置为 1.5A，最终由约 1.3～1.44A 的硬件限制提供失效保护。

如果后续测试证明设备在充电时的系统功耗较高，可评估将 ILIM 电阻改为 200Ω、IINLIM 改为 2.0A。在修改前必须确认 9V PD 合同、输入连接器、BQ25895、电感和 PCB 热设计均有足够余量。

### 4.2 修改 TS 电池温度检测分压

当前原理图使用的温控网络约为：

```text
R72 = 5.23kΩ
R73 = 30.1kΩ
R74 = 10kΩ、B≈3435 NTC
```

该组合接近 BQ25895 参考设计中的 0～45°C 充电窗口，不符合本电池要求的 10～45°C。

推荐修改为：

```text
R72：5.23kΩ → 5.69kΩ，1%
R73：30.1kΩ → 100kΩ，1%
R74：10kΩ、B≈3435 NTC，保持不变
```

连接关系保持如下：

```text
REGN ── R72 ── TS
                 ├── R73 ── AGND
                 └── NTC ── AGND
```

上述阻值按 BQ25895 典型 TS 阈值和 10kΩ/B3435 NTC 计算。实际停充温度会受到以下误差影响：

- NTC 25°C 阻值误差
- NTC B 值误差
- R72/R73 阻值误差
- BQ25895 TS 比较器阈值误差
- NTC 与电芯之间的热耦合和热延迟

因此量产前必须进行温箱验证，重点测试 8～12°C 和 43～47°C 区间。NTC 应贴近电池本体，而不是仅测量充电芯片或主板温度。

### 4.3 CHARGE_EN_N 改为默认禁止充电

BQ25895 的 CE 为低有效，且芯片复位默认快充电流为 2.048A。如果 `CHARGE_EN_N` 默认下拉，上电后会在 MCU 完成 I2C 配置前按默认参数开始充电。

推荐把 `CHARGE_EN_N` 的默认状态改为上拉：

```text
CHARGE_EN_N ── 47kΩ～100kΩ ── 3V3_Aon
```

上电时 CE 保持高电平，默认禁止充电。MCU 完成参数写入和回读校验后，再把 CE 拉低开始充电。

## 5. BQ25895 寄存器设置

寄存器应采用读-改-写方式，只修改相关字段，避免覆盖同一寄存器中的其他功能位。

### 5.1 REG00：输入电流限制

```text
EN_HIZ  = 0
EN_ILIM = 1
IINLIM  = 1.5A
```

IINLIM 的偏移为 100mA、步进为 50mA，因此 1.5A 对应字段值：

```text
(1500mA - 100mA) / 50mA = 28 = 0x1C
```

### 5.2 REG04：快充电流

BQ25895 的 ICHG 步进为 64mA：

```text
1600mA / 64mA = 25 = 0x19
REG04 = 0x19（EN_PUMPX=0 时）
```

不要继续使用原设计说明中的约 3A 充电电流。

### 5.3 REG05：预充和终止电流

```text
IPRECHG = 256mA
ITERM   = 64mA
REG05   = 0x30
```

电池组的 0.01C 为 80mA。BQ25895 可选的相邻档位为 64mA 和 128mA，因此选择 64mA。

### 5.4 REG06：充电电压

```text
VREG    = 4.192V
BATLOWV = 3.0V
VRECHG  = 100mV
REG06   = 0x5A
```

BQ25895 的电压步进为 16mV，4.2V 附近可选 4.192V 或 4.208V。为避免电压误差和线路补偿使电池端超过 4.2V，本方案选择 4.192V。

首版应关闭 REG08 中的 BAT_COMP 和 VCLAMP。只有在测得充电路径压降并完成最坏情况验证后，才允许启用线路压降补偿。

### 5.5 REG07：终止、看门狗和安全计时器

```text
EN_TERM   = 1
EN_TIMER  = 1
CHG_TIMER = 8小时
```

I2C 看门狗可根据软件架构选择禁用或定期喂狗。如果启用看门狗，软件必须确保看门狗复位不会把 ICHG/VREG 等字段恢复成不符合本方案的默认值。

### 5.6 REG08：芯片热调节

```text
BAT_COMP = 0
VCLAMP   = 0
TREG     = 80°C
```

TREG 监控的是 BQ25895 结温，只能用于限制充电器自身发热，不能代替 TS 引脚上的电池 NTC。

### 5.7 REG0D：9V 输入电压调节

```text
FORCE_VINDPM = 1
VINDPM       = 8.2V
```

VINDPM 的偏移为 2.6V、步进为 100mV：

```text
(8.2V - 2.6V) / 0.1V = 56 = 0x38
```

设置 8.2V 可以在 9V PD 输入下为电源和线缆压降留出余量，避免适配器电压轻微下降时充电器频繁进入输入电压调节。

## 6. 推荐的充电启动顺序

系统上电后按以下顺序操作：

1. 保持 `CHARGE_EN_N` 为高，禁止充电。
2. 检查 BQ25895 I2C 通信和器件 ID/复位状态。
3. 读取并记录全部关键寄存器。
4. 配置 IINLIM、ICHG、IPRECHG、ITERM、VREG、VINDPM、TREG 和安全计时器。
5. 关闭 BAT_COMP/VCLAMP。
6. 回读所有配置并逐字段校验。
7. 检查 REG0C，确认没有 TS cold、TS hot、BAT OVP 或其他故障。
8. 确认输入为有效的 9V PD 电源，并检查 VBUS ADC 读数。
9. 将 `CHARGE_EN_N` 拉低，开始充电。
10. 充电期间持续监控 VBAT、IBAT、VBUS、TS、THERM_STAT、CHRG_STAT 和故障寄存器。

当发生以下任一条件时，应立即停止充电：

- 电池温度低于 10°C 或高于 45°C
- 电池端电压异常
- BQ25895 报告热调节持续时间过长或热关断
- 输入电源反复进入 VINDPM/IINDPM
- 充电安全计时器超时
- 电池保护板断开
- NTC 开路、短路或读数不可信

## 7. 电池并联与保护要求

优先使用厂家组装并完成匹配的 1S2P 8000mAh 电池包，并由一块适用于 1S2P 的公共保护板保护。

保护板至少应满足：

- 4.2V 锂电池体系
- 允许充电电流不低于 2A
- 连续放电能力高于整机最大负载
- 过充、过放、过流和短路保护
- 支持并连接出电池 NTC

两颗电芯应使用相同型号、相同批次、相近容量和内阻，并采用对称走线或汇流连接，尽量保证充放电电流均分。

禁止将电压差较大、老化程度不同或各自带独立保护板的两块电池直接并联。首次并联前必须确认两颗电芯电压足够接近，并控制均衡浪涌电流。

## 8. 硬件和热设计检查

虽然本方案仅使用 1.6A 电池充电电流，PCB 仍需检查：

- 2.2µH 充电电感的饱和电流和温升电流应有足够余量，建议饱和电流不低于约 4A。
- BQ25895 PowerPAD 必须完整焊接，并通过多颗散热过孔连接地平面。
- VBUS、PMID、SW、SYS、BAT 和 PGND 的高 di/dt 回路必须短且宽。
- 输入、PMID、SYS 和 BAT 电容应紧贴对应引脚和 PGND 回流点。
- PGND 与模拟地应按数据手册建议在芯片附近单点连接。
- 电池连接器、保护板、线材和焊点应按整机最大放电电流选型，而不是只按 1.6A 充电电流选型。

## 9. 样机验证清单

至少完成以下测试后才能冻结设计：

- 5V 普通 USB 输入和 9V PD 输入分别测试。
- 电池电量从低电量到充满的完整 CC/CV 曲线记录。
- 实测恒流阶段电池电流约为 1.6A。
- 实测电池连接器端最高电压，并确认在器件误差和温度变化下不超过允许值。
- 验证终止电流约为 64mA，且不会因系统负载反复终止/重充。
- 10°C 冷端和 45°C 热端停充与恢复测试。
- NTC 开路、短路故障测试。
- 低压适配器、长线缆和输入压降测试。
- 满负载边运行边充电测试。
- BQ25895、电感、电容、电池、连接器和保护板的最高温升测试。
- MCU 复位、I2C 失效和看门狗复位时，确认不会恢复到不安全的默认充电参数。
- 两颗并联电芯的支路充放电电流和温差测试。
